# لاسلكي الفريق (Walkie)
إعداد وهندسة: المهندس أنور محمد عايض الأشول

## البناء
1. Android Studio (Koala أو أحدث) ← File > Open ← اختر مجلد AnwarWalkie ← انتظر Gradle Sync.
2. لنسخة تجريبية: Build > Build APK(s) ← app/build/outputs/apk/debug/app-debug.apk
3. لنسخة نهائية: Build > Generate Signed Bundle / APK ← APK ← أنشئ مفتاح توقيع (Keystore) واحتفظ به.

## الاختبار
جهازان أو أكثر على نفس شبكة Wi-Fi (أو هوتسبوت أحدهما)، نفس "رمز الشبكة" ونفس القناة.
اضغط "غير متصل" ثم اضغط مطولاً على الزر الكبير للتحدث.

## الميزات
- بث صوتي جماعي (Push-to-Talk) على 8 قنوات عبر UDP Multicast، بلا إنترنت.
- إنشاء شبكة محلية (LocalOnlyHotspot) وعرض QR، والانضمام بمسح QR (أندرويد 10+).
- مكالمات مباشرة بين شخصين (رنين/رد/رفض/كتم/سماعة/إنهاء) وإشعار مكالمة واردة بشاشة كاملة.
- أشخاص محفوظون تلقائياً، التحدث بأزرار الصوت، نغمات واهتزاز، إبقاء الشاشة، استثناء البطارية.
- إشعار/تشغيل عند الإقلاع (أندرويد 14+ يمنع تشغيل خدمة الميكروفون من الإقلاع، فيظهر إشعار للضغط عليه).

## ملاحظات
- لم يُجرَّب الكود على جهاز (كُتب دون Android SDK). عند أي خطأ ترجمة أو تشغيل أرسله وسأصلحه.
- بعض الراوترات تحجب Multicast بين الأجهزة (AP isolation)؛ عطّلها إن لم يظهر المشاركون.
- الانضمام عبر QR يستخدم Google Play Services (ماسح الباركود الجاهز)، ويلزم أن يكون موجوداً على الجهاز.
- الصوت PCM 16kHz غير مضغوط (~256kbps) مناسب للشبكة المحلية؛ الضغط بـ Opus تحسين مستقبلي.

## بناء APK بدون Android Studio (GitHub Actions)
1. أنشئ مستودعاً جديداً على github.com وارفع محتويات هذا المجلد (بما فيها .github).
2. افتح تبويب Actions ← "Build APK" ← Run workflow (يعمل تلقائياً عند الرفع).
3. بعد دقائق افتح التشغيل الناجح ونزّل الملف من Artifacts: AnwarWalkie-apk (app-debug.apk).
